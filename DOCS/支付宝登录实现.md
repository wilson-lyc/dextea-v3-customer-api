# 支付宝登录实现文档

本文档说明本项目（dextea-customer-api）如何接入支付宝登录，涵盖原理、接入准备、整体流程、核心代码与配置说明。

---

## 1. 概述

支付宝登录基于 OAuth2 授权码模式（Authorization Code）的变体。核心思想是：

1. **前端**通过支付宝开放平台 SDK（或 H5/小程序授权组件）引导用户授权，拿到一个一次性的 `auth_code`（授权码）。
2. **后端**用该 `auth_code` 调用支付宝网关接口 `alipay.system.oauth.token`，换取用户的 `user_id`（在本项目中即 **支付宝 OpenID**）。
3. 后端以 OpenID 在用户表中查找或创建客户账号，并签发本系统的 JWT，完成登录。

> 本项目不依赖前端把用户标识直接传回来，而是始终由服务端向支付宝换取并校验，避免伪造身份。

---

## 2. 接入前准备（支付宝开放平台）

1. 登录 [支付宝开放平台](https://open.alipay.com/)，创建**网页/移动应用**，通过审核后获得 `APPID`。
2. 在「应用信息 → 开发设置」中：
   - **接口加签方式**选择 **RSA2**。
   - 由平台生成或自行生成一对 RSA 密钥：
     - **应用私钥**（Application Private Key）：仅服务端持有，用于给请求签名。
     - **应用公钥**（Application Public Key）：上传给支付宝。
   - 平台会给出 **支付宝公钥（Alipay Public Key）**：用于校验支付宝返回的响应签名（可选，强烈建议配置）。
3. 配置 **授权回调地址**（部分场景需要，如网页授权）。
4. 记录生产网关地址：`https://openapi.alipay.com/gateway.do`（沙箱网关不同，可用于联调）。

密钥格式说明：支付宝私钥/公钥可以是 PEM 文本，也可以是**裸 base64 字符串**。本项目 `normalizeKey` 会自动把裸 base64 规整为 PEM，因此两种格式均可直接填入配置。

---

## 3. 整体流程

1. 前端调用支付宝授权 SDK，用户确认后拿到 `auth_code`。
2. 前端把 `auth_code` 与 `platform=alipay` 通过登录接口发给后端。
3. 后端用应用私钥对请求参数做 **RSA2 签名**，请求支付宝网关。
4. 支付宝返回 `user_id`；若配置了支付宝公钥，后端会先**校验响应签名**再使用。
5. 后端以 OpenID 查询客户，不存在则创建（默认昵称「德贤茶友」、状态正常），然后生成 JWT。
6. 后端返回 `token` 与 `customer` 信息，前端保存令牌用于后续鉴权。

### 4.1 请求签名（RSA2）

`s alipay.system.oauth.token` 要求对所有非空参数按**字典序**拼接为 `k=v&k=v` 形式，用 SHA256 做摘要后用**应用私钥**做 PKCS1v15 签名，再做 Base64：

```go
// internal/customer/alipay.go
func rsa2Sign(params map[string]string, key *rsa.PrivateKey) (string, error) {
    keys := make([]string, 0, len(params))
    for k := range params {
        keys = append(keys, k)
    }
    sort.Strings(keys)

    var b bytes.Buffer
    for _, k := range keys {
        if params[k] == "" {
            continue
        }
        if b.Len() > 0 {
            b.WriteString("&")
        }
        b.WriteString(k)
        b.WriteString("=")
        b.WriteString(params[k])
    }

    h := sha256.New()
    h.Write(b.Bytes())
    digest := h.Sum(nil)

    sig, err := rsa.SignPKCS1v15(rand.Reader, key, crypto.SHA256, digest)
    if err != nil {
        return "", err
    }
    return base64.StdEncoding.EncodeToString(sig), nil
}
```

### 4.2 用 code 换取 OpenID

```go
// internal/customer/alipay.go
func (c *alipayClient) exchangeCode(ctx context.Context, code string) (string, error) {
    params := map[string]string{
        "app_id":     c.appID,
        "method":     alipayOAuthMethod, // "alipay.system.oauth.token"
        "format":     "JSON",
        "charset":    "utf-8",
        "sign_type":  "RSA2",
        "timestamp":  time.Now().Format("2006-01-02 15:04:05"),
        "version":    "1.0",
        "grant_type": "authorization_code",
        "code":       code,
    }
    // ... 签名、POST 网关、解析并校验响应 ...
}
```

### 4.3 业务串联

```go
// internal/customer/service.go
func (s *Service) Login(ctx context.Context, req LoginRequest) (*LoginResponse, error) {
    var openID string
    var err error
    switch req.Platform {
    case PlatformAlipay:
        openID, err = s.exchangeAlipayOpenID(ctx, req.Code)
    // ...
    }
    // 查/建客户
    cust, err := s.repo.FindByAlipayOpenID(ctx, openID)
    if cust == nil {
        cust, err = s.repo.Create(ctx, &Customer{
            Name:         defaultNewCustomerNickname,
            AlipayOpenID: openID,
            Status:       1,
        })
    }
    // 签发 JWT
    token, err := jwt.Generate(s.cfg.JWTSecret, jwt.Claims{
        UID:      cust.ID,
        Platform: string(req.Platform),
    }, s.cfg.JWTExpireSeconds())
    return &LoginResponse{Token: token, Customer: cust}, nil
}
```

## 5. 配置说明

在项目根目录的 `.env`（或部署环境变量）中配置以下项：

| 配置项 | 环境变量 | 说明 |
| --- | --- | --- |
| 应用 APPID | `ALIPAY_APP_ID` | 支付宝开放平台分配的应用 ID，**必填** |
| 应用私钥 | `ALIPAY_PRIVATE_KEY` | 应用私钥（PEM 或裸 base64），**必填** |
| 支付宝公钥 | `ALIPAY_PUBLIC_KEY` | 平台提供的支付宝公钥，用于校验响应签名（可选但建议） |
| 网关地址 | `ALIPAY_GATEWAY` | 留空则使用生产网关 `https://openapi.alipay.com/gateway.do`；联调沙箱时填写沙箱地址 |

> 仅当 `ALIPAY_APP_ID` 与 `ALIPAY_PRIVATE_KEY` 同时非空时，后端才会初始化支付宝客户端；否则登录时返回「支付宝未配置」错误。

## 6. 接口说明

**请求**

```
POST /customers/login
Content-Type: application/json
```

```json
{
  "code": "前端获取的支付宝 auth_code",
  "platform": "alipay"
}
```

**响应**

```json
{
  "code": 0,
  "data": {
    "token": "eyJhbGciOi...",
    "customer": {
      "id": 1,
      "name": "德贤茶友",
      "alipay_open_id": "2088xxxx",
      "status": 1
    }
  }
}
```

字段约束：`code` 与 `platform` 必填；`platform` 目前仅支持 `alipay`（微信登录尚未实现，会返回「平台暂不支持」）。

## 7. 安全与注意事项

- **签名必须使用 RSA2（SHA256）**：本项目固定 `sign_type=RSA2`，与开放平台「接口加签方式」保持一致。
- **响应验签**：配置了支付宝公钥后，`parseOAuthResponse` 会对返回的 `sign` 做 PKCS1v15 + SHA256 校验，防止伪造响应。
- **私钥保密**：应用私钥只存在于服务端/环境变量，绝不暴露给前端或提交到仓库。
- **code 一次性**：`auth_code` 有效期短且只能用一次，不可复用；若换取失败需前端重新发起授权。
- **OpenID 即身份**：`user_id` 在同一应用下唯一，直接作为客户表的 `alipay_open_id` 进行查重，避免重复建号。

---

## 8. 常见问题

- **返回「支付宝未配置」**：检查 `ALIPAY_APP_ID`、`ALIPAY_PRIVATE_KEY` 是否都非空。
- **签名错误（illegal_sign）**：确认私钥与开放平台「应用公钥」匹配，且加签方式为 RSA2；注意参数需按字典序、非空参与签名。
- **返回 sub_code 如 `invalid_code` / `code expired`**：授权码已过期或重复使用，需前端重新获取。
- **响应验签不通过**：核对 `ALIPAY_PUBLIC_KEY` 是否为「支付宝公钥」而非「应用公钥」。
